# 魔法幸存者（Pigeon）

一款基于 Canvas 的轻量 Roguelite 生存小游戏：单机、无需构建、浏览器直接打开即玩。

## 在线游玩

🌐 **[立即开始游戏](https://rougelike-13h.pages.dev)**

手机端建议使用右上角全屏按钮获得沉浸体验；桌面端支持键盘操作。

## 快速开始

双击打开 `index.html` 即可游玩，或使用任意静态服务器（如 `python -m http.server`）托管整个目录。

## 游戏玩法

- **目标**：在越来越密集的敌人浪潮中生存，击杀敌人获取经验、升级武器
- **武器**：魔法弹、飞刃、冰霜、闪电链、陨石、暗影精灵，可组合进化
- **难度**：简单 / 普通 / 困难 / 地狱，影响敌人属性、出怪频率与初始生命
- **精英波次**：每 60 秒一波精英来袭，清空后获得宝箱奖励
- **Boss**：死神骑士（剑气/冲击波）、虫巢母皇（召唤/毒液）、暗影刺客（瞬影突进/影刃回旋），击杀掉落专属道具
- **地图事件**：治疗祭坛（回复 50% 生命）、风险祭坛（生命降至 1，伤害 +50%）、传送门（位移并留下减速区域）
- **灵魂宝库 / 圣物商店 / 成就系统**：局外成长与收集要素
- **死神之指**：开启后进入"禁奖励"高难模式（需在灵魂宝库购买解锁，局内可切换自动/手动）

## 操作方式

- **桌面端**：WASD / 方向键移动，数字键快速选择升级
- **移动端**：在屏幕任意位置按住并拖动即可移动（虚拟摇杆跟随落点出现），升级时点按卡片选择；右上角按钮可暂停、静音、全屏

## 开发说明

- 无构建步骤、无依赖，原生 HTML/CSS/JS，可直接修改刷新
- JS 文件为顶层共享作用域，按固定顺序加载，**新增 JS 文件时请保持依赖顺序**（`00` → `11`）
- 快捷键：`P` / `Esc` 暂停，`M` 静音，全屏按钮在右上角
